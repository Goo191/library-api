# YouLibrary: Smart University Library Management System

A back-end system for a university library, built as a graduation project at Misr Higher Institute for Commerce & Computers (M.E.T) for its students and staff.

It exposes a REST API for client apps (student login, book browsing, QR-based borrowing and returning, library check-in/out) and includes an admin panel for library staff.

## Features

**Student API**
- Token-based authentication with Laravel Sanctum (login with student name and student ID, logout, current student)
- Student profile: view and update
- Browse books: all books, regular books, graduation books, study materials, by category, by title
- View a book's PDF file
- Search books, with a per-student search history (list and delete entries)
- Borrowing history for the logged-in student

**QR-based workflows**
- Each book has its own QR code
- Borrow and return a book by scanning its QR code
  - Borrowing is rejected when the book is out of stock
  - Borrowing decreases the stock, returning increases it
  - Returning requires an active borrow by the same student
- Verify that a scanned QR code matches the book currently on screen
- Library check-in / check-out by scanning the library QR code, with a status endpoint
- The library QR code is regenerated by a scheduled Artisan command (`library:generate-qr`)

**Admin panel (Filament)**
- Resources for books, authors, categories, borrows, QR logs, and student courses
- A page for the library QR code

**API documentation**
- Interactive Swagger UI generated with L5-Swagger at `/api/documentation`

## API Overview

All endpoints except login require a Bearer token (`Authorization: Bearer {token}`).

| Area | Method | Endpoint |
|---|---|---|
| Auth | POST | `/api/login` |
| Auth | POST | `/api/logout` |
| Auth | GET | `/api/me` |
| Students | GET / PUT | `/api/students/{id}` |
| Books | GET | `/api/books`, `/api/books/all`, `/api/books/regular`, `/api/books/graduation`, `/api/books/study-materials` |
| Books | GET | `/api/books/{title}`, `/api/books/title/{title}`, `/api/books/{id}/view-pdf` |
| Books | POST / PUT / DELETE | `/api/books`, `/api/books/{id}` |
| Borrowing | POST | `/api/books/borrow`, `/api/books/return` |
| Borrowing | GET | `/api/books/history`, `/api/books/current/{title}` |
| QR | POST | `/api/books/verify-scan` |
| QR | POST | `/api/qr-login`, `/api/qr-logout` |
| QR | GET | `/api/qr-status` |
| Categories | GET | `/api/categories`, `/api/categories/{name}/books` |
| Search | GET | `/api/search`, `/api/search/history` |
| Search | DELETE | `/api/search/history/{id}` |

Full request and response details are in the Swagger UI at `/api/documentation`.

## Data Model

Main entities: `students`, `books`, `authors`, `categories`, `borrows`, `qr_logs`, `courses`, `search_history`.

- A book belongs to one category and has many authors (many-to-many via `author_book`)
- A student has many borrows, QR logs, and search history entries
- Students and courses are linked many-to-many via `student_course`
- A borrow links one student to one book, with `borrow_date`, `return_date`, and `borrow_status`

## Getting Started

**Requirements:** PHP 8.1+, Composer, MySQL, Node.js and npm

```bash
git clone https://github.com/Goo191/library-api.git
cd library-api

composer install
npm install

cp .env.example .env
php artisan key:generate
```

Set your database credentials in `.env`, then create the database and load the schema:

```bash
# import the schema (see database/schema.sql)
mysql -u root -p your_database < database/schema.sql

php artisan migrate
```

Run the app:

```bash
php artisan serve
php artisan schedule:work   # keeps the library QR code up to date
```

- API docs: `http://localhost:8000/api/documentation`
- Admin panel: `http://localhost:8000/admin` (create a user with `php artisan make:filament-user`)
